# DATABASE AUTOMATION USING VIEWS AND PROCEDURES

## INVENTORY MANAGEMENT SYSTEM

### Project Description

This project focuses on automating database operations using SQL Views and Stored Procedures.

It helps to manage customer details, product information, orders, payments, sales reports, and inventory stock efficiently.
